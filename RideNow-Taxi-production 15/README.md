# RideNow Taxi production website foundation

AI/SEO visibility is a core requirement, not an add-on. Includes Next.js/React/TypeScript, responsive premium black/gold/white design, service/route/cruise-port/tour/vehicle/area/cruise-line architecture, metadata, canonical base URL, LocalBusiness JSON-LD, sitemap, robots.txt with OAI-SearchBot access, internal linking, FAQs and WhatsApp CTA.

Before live deployment: connect real booking/database/payment/email/flight APIs, analytics/Search Console, legal pages, final photography and production credentials. Run `npm install`, `npm run build`, then `npm start`.
